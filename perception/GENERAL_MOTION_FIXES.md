# 弯道跟车与信号灯约束修正

2026-10-03，修复分支使用 `successor-continuation-v3`。固定成员入口、Python 3.6、SDK 连接及控制开关保持原约定。

## 故障证据与运动模型

正式 Sensor 刹车帧显示，两次前车净距约 49.96 m、75.91 m，决策均为 FOLLOW。前车宽 2.23 m，沿掉头曲线行驶。原规划把相对采样弦的横向速度按至少 3 s 的直线漂移外推，超过剩余车道宽度，拒绝轨迹并触发监护制动。

`core/route_motion.py` 在地图归属、所属路线段、实测宽度、尺寸和朝向均可信时，利用车身纵向范围内的道路切线范围分离转弯运动与侧滑。车身必须仍在所属车道、朝向符合这些切线；剩余侧滑仍按原窗口扩大包络。这是假设目标沿已知道路行驶的模型，不预测突然切入或横向加速度；横穿、迎面、未知朝向及几何不足仍保护。

未知/邻道目标先检查其车身包络及观察时间内的线段扫掠能否接触已知前方路线，包含端点之间的横穿。不相关目标不覆盖跟车或信号约束；未选择的已知分叉目标仍保守处理。规划的“不支持运动”否决针对当前规划范围及制动距离内的潜在冲突，目标当前位置的静态停车边界仍保留。有效远距 FOLLOW 后目标消失不再触发障碍清除急停；真实静止/危险目标消失仍需清除确认及保持释放。

地图最近车道查询在接头处迟更新时，感知可依据此前验证的后继、共享端点、实测宽度及高度恢复目标归属。主车另外要求局部朝向符合、只允许进入直接后继，避免跳到远处自交段。任务/路线提示变化清空旧选择，无已验证后继时保留原边界。

反向微动统一采用控制已有的 0.05 m/s 停稳门槛：实测速度幅值超过门槛仍保护。原制动后 −0.005 至 −0.031 m/s 回退不再被下游反复拒绝。

## 曲线速度恢复

实帧入弯速度 5.3354 m/s，当前曲线暂定上限 5.2463 m/s，原逻辑直接急停。轻微曲线超速允许按已配置减速度短时恢复：`PlannerSettings.curve_recovery_time_s` 默认 0.2 s、最大配置 0.5 s；初始超限不得超过减速度乘恢复时间，窗口末端必须重新满足曲线限制。保留实测初速度及有界减速，不制造瞬间速度跳变。

这是已发生超速后的恢复轨迹，窗口内曲线暂定限值可能超出，不能标为全程满足横向加速度限制。停车边界、前方限速均不放宽；较大超速或窗口内无法恢复仍急停。该窗口及已有加减速度参数尚待平台响应标定。

## 任务分叉选择

有效任务路径点仅作为选择 HDMap 连通路线的提示，不连成驾驶轨迹。在分叉处搜索连接正常且能覆盖下一任务点的路径，最多 128 个状态、32 段。不同首分支同等可达、连接断开、竞争分支查询失败、无效提示或预算不足仍保留 `ambiguous_successor` 停车边界。缓存随任务/提示变化失效。这不是变道、绕障或任意路网全局规划。

## 公共字段与信号质量

灯控质量复用 P0 分支 `70a6e16` 的部分实现，未合并整条 P0 分支，也不包含其全部业务停车参数。

| 字段 | 生产者与消费语义 |
| --- | --- |
| `TrafficControl.association_valid` | 适配层确认静态灯/停止线关联查询，感知发布；不等于动态灯色可用 |
| `signal_presence` | present/absent/unknown；地图确认无适用前方信号才可发布 absent |
| `required` | 适用灯或损坏信号记录需要保护；缺省 false 保留旧合同 |
| `source_status.traffic` | 感知发布 association_valid、signal_presence、required、usable、quality 与 host_query 时钟语义，不伪称 SDK 同步帧 |
| `Target.heading` | 缺失为 None，适配层/感知不制造 0 rad 朝向；规划保留外接圆及未知运动保护 |

`core/traffic_quality.py` 由决策、规划和独立监护消费。灯色读失败保留关联停止线候选并清除旧绿灯。可信停止线已知时允许按距离减速停车，缺线或关联不明时保守保持/制动。远处可读绿灯不能替代近处读失败的灯；损坏记录可能含更近停止线，因此距离也标未知。10/20/37/38 等信号任务在关联查询未知时保护，地图确认无适用灯时可继续。

接近停车仍可输出 KEEP_LANE/FOLLOW 加 `stop_distance`。规划遵守停车边界，监护只在同帧有效决策及轨迹均有可信边界时允许接近；新鲜绿灯解除信号约束，真实障碍仍保留。通用序列化保留新增字段，旧快照默认值及回放重建兼容；未知关联不能变成已确认无灯。

## 验证与现场边界

新增测试覆盖弯道跟车、横穿扫掠、邻道迎面目标、远距前车消失、真实危险清除、接头归属、任务分叉和缓存变化、反向微动、曲线速度恢复、信号读失败、旧绿灯拒绝、独立监护和绿灯释放。

SimOne Python 3.6 完整 `python -B -m unittest discover -s tests -v`：428 项全部通过，83.194 s，含既有真实成员入口的闭环模型。首次沙箱运行的临时快照写入失败与算法失败分开处理；最终完整运行无跳过、无失败。

真实帧回放仅重绑定过期的本机截止时间，保留坐标、速度和来源；7 个原运动拒绝帧已保持 FOLLOW 并输出非急停前进轨迹，2 个曲线限速拒绝帧已输出减速恢复。它不重跑感知归属、不证明状态机连续闭环；目标源失效帧仍保护，两个旧接头归属帧需以新感知复跑验证。

红绿灯旧日志存在路线无法投影的目标冲突，但缺完整失败目标/灯色帧，不能确定全部现场原因。平台需复跑连续跟车、前车停走、红灯接近/保持、绿灯释放及真实近端障碍。启动/结束脚本路径不变，结束旧进程后才加载新代码。
