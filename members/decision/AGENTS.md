# 决策成员约束

继承根 `AGENTS.md`。本文件自然作用于本目录；`members/decision_stub.py` 及决策测试由根规则要求补充读取本文件。

- 职责：根据 `Perception` 选择行为目标，经 `decide(perception)` 返回 `DecisionTarget`；保持车道、跟车、停车和紧急制动等模式以现有 `DecisionMode` 为准。
- 可修改本目录算法、固定决策入口和相关测试；不直接承担感知、规划、控制或 SDK 接入，不调用其内部算法。
- 明确目标速度、目标车道、停车距离与 `valid` 的语义。未提供的数据不能当作已知事实；新增模式、字段或失效反馈先按公共接口流程协调。
- 验证：构造输入测试无效感知、行为切换、目标一致性及边界条件；检查规划消费者能理解输出，不能以决策单测通过代替整车验证。
- Skill：本项目 `path-planning` 已限定为轨迹规划，不能因上游曾含 behavior planning 就把轨迹职责移到本模块；需要其他专业 Skill 时按实际任务选择。
