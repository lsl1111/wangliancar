## 入口与范围

- 固定入口仍是 [`plan(perception, decision)`](../planning_stub.py)，调用 [`lane_planner.py`](lane_planner.py)。Python 3.6，仅标准库。
- 输入输出沿用 `Perception + DecisionTarget -> Trajectory`；本次由队长在 `LaneContext` 增补连续前方参考字段并接入感知。固定成员入口及轨迹、控制合同保持原样。
- 上游 `reference_preview.py` 保留作旧预览实现，固定入口已切换到 V1。
- 保持当前车道、接受决策给定速度、停车和紧急停车请求；不选择行为、不直接发送控制。
- `ego.gear` 保留 GPS 的原始变速箱位置，不按控制指令 N/D/R/P 枚举解释；前进规划以沿车头方向的有符号速度拒绝实际反向运动，反馈值 2 不单独表示倒车。
- `FOLLOW` 仅接受决策提供的速度/停车约束，不实现前车选择或车距策略。出现有效传感器目标物（包括邻道目标）仍明确拒绝移动。公共需求表不要求目标流的场景，在目标配置未知或目标流缺失时也可继续生成车道参考轨迹；不把未知配置伪装成“确认未配置”，不把缺失流当作有效空列表，并在原因中明确“未验证碰撞净空”。Ground Truth 仍只作诊断。必需目标流缺失继续拒绝。

## 算法与输出约定

1. 检查感知、决策的有效性、数值、来源帧与有效期；输出继承决策的 `frame_id/timestamp/valid_until`，不延长数据寿命。结束时再次检查有效期。
2. 清除参考线连续重复点，检查连续前方参考包含原样的当前车道前缀；用当前车道中心线定位 GPS 进度，再沿连续参考向前截取，避免跳到后续交叉或邻近路段。**首点是中心线上的参考点，不一定等于车辆实际位置**；只接受小幅跟踪误差，不生成横向回归路径。
3. 沿路径累计距离建立统一采样网格，并保留原始顶点，避免跨折角抄近路；因此点距不一定全相等，但不超过设置值。保留精确的停车/截取末端，不向地图外延伸。
4. 航向取前方线段方向，并连续展开角度，避免经过 ±π 时突然跳变。航向可能超出 `[-π, π]`；控制计算角度误差时应归一化。
5. 用完整原始地图的相邻转角与原始弧长估算弯道速度上限，包括主车身后的邻近顶点，再把顶点速度上限按速度平方插值到输出采样点；不在插入的新点或随主车移动变化的投影点上重新估算曲率，避免限速随采样相位跳变。输出几何的明显尖角仍直接拒绝。该估计不能证明车辆转向可行，也没有把折线变成曲率连续曲线。
6. 用 `v_next² <= v_prev² + 2*a*ds` 向前限制加速，向后限制制动；正常移动轨迹的初速度保留实测车速。若当前已超过目标速度，逐步减速，不瞬间把初速度改成目标值。
7. 每段按 `dt = 2*ds/(v_prev + v_next)` 计算时间；等价于该段采用恒定纵向加速度。首点时间为 0，其余严格递增。短路径起步后停车保留中间速度点，避免“两个零速点之间移动”。

空间使用地图坐标米，速度为 m/s，航向为弧度，相对时间为秒。项目[场景验收说明](../../perception/SCENE_DATA_ACCEPTANCE.md)已记录 GPS 参考点为后轴中心；仍需和控制组核对实际模型及跟踪参考点。

### 停车与失效

| 情形 | V1 行为 |
| --- | --- |
| 正常行驶 | 接受决策速度，应用加减速、弯道及已知地图末端的限制 |
| `STOP` | 必须有非负 `stop_distance`，解释为沿参考路径从当前 GPS 投影到停车点的距离；不再额外减一次车头余量 |
| 非 STOP 模式但目标速度为 0 | 若车辆在动，生成受限减速过程；已静止则保持原位置 |
| 非负停车距离出现在其他模式 | 同样作为不得越过的距离上限，叠加已知地图末端约束 |
| 已知参考末端 | 优先按连续前方参考安排末端零速；可接续的车道段交界继续前进。后继缺失、分叉未选或坏连接也保留已知边界停车，原因见 `forward_reference_status` |
| 设定减速度下无法停车/进入弯道 | 采用既有 `emergency_stop=True`、零速重复位置点的请求格式；这表示请求制动，**不是物理上瞬间停住的轨迹** |
| `EMERGENCY_BRAKE` | 有效自车/决策下直接保留紧急请求，无需车道或目标观测可用 |
| 过期、坏几何、换道、倒车、目标物非空等 | `valid=False`、清空点列，`reason/errors` 给出原因，不静默换道或忽略障碍物 |

`Trajectory.target_speed` 保留决策的目标速度（STOP/零速请求为 0），**实际执行的速度安排在每个点的 `speed` 中**。地图末端/弯道可能使点速度低于这个标量，控制端不能只读取标量。

`stop_required/stop_distance` 记录停车要求和当前已知可用距离；STOP、非负距离要求、零速请求或地图末端进入当前视野时会置位。控制侧需要结合点速度理解它，而不是一见此标志就跳过减速过程。

`valid=True` 仅表示通过本版参考几何与速度时间检查；不代表通过车身边界、碰撞、转向或整车验证。无效轨迹由运行监护选择制动出口；实际发送必须同时启用发送和安全制动配置，默认观察模式不会发车辆指令。

## 临时参数

集中在 `PlannerSettings`，可以通过 `build_trajectory(p, d, settings)` 在离线实验中替换，固定入口使用默认值。以下均为**实验设置，尚未标定为车辆能力或赛事阈值**。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| 采样网格间距 | 1 m | 控制轨迹点密度；原始顶点额外保留 |
| 前方长度 | 60 m | 单次规划覆盖上限，不是强制停车点 |
| 加速 / 减速上限 | 1 / 2 m/s² | 正常速度安排 |
| 横向加速度参考上限 | 1.5 m/s² | 离散弯道限速估计 |
| 最大投影距离 | 0.5 m | 超出时交回横向恢复需求，不直接跳到中心线 |
| 最大初始航向误差 | π/4 | 排除明显不匹配的参考方向 |
| 最大相邻折角 | 0.35 rad | 拒绝尖角；不是车辆最大转角 |
| 静止请求两点间隔 | 0.1 s | 满足既有轨迹时间合同 |

另限制原始中心线不超过 20000 点、输出不超过 2000 点；超限返回无效，不任意截断原始道路。没有加入转向角、车宽、轴距或障碍物安全距离的猜测值。

| 联调前：队长 / 仿真数据 | 连续 GPS/中心线/目标源快照及直道、弯道、停车观察记录 | 已用历史地图和停车位置离线复查后继接续；新接续代码尚待真实平台运行，传感器范围、跟踪及制动响应仍需验收 |
| 障碍物阶段：感知 / 规划 / 车辆配置 | 主车包络、目标尺寸和朝向语义、观测范围/漏检边界、动态预测与不确定性约定 | 不能把空目标等同于全道路无障碍；暂拒绝非空目标的移动规划，不支持实质跟车/避障 |
