## 显式输入与输出

`validate_candidate(points, motion_direction, vehicle, limits, corridor, obstacles, budget)` 使用已有 `TrajectoryPoint`；位置是后轴中心，heading 是车体航向，速度非负，整段方向为整数 +1/-1。倒车时路径向后延伸，heading 不加 π。

| 参数类型 | 内容 / 单位 |
| --- | --- |
| `VehicleGeometry` | 后轴到车头/车尾、半宽、轴距，m；不借用目标物中心作为主车参考 |
| `MotionLimits` | 速度、纵向加减速度、横向加速度、最大前轮角及转角变化率；另显式给方向角/距离误差容限 |
| `corridor` | 明确已核实的凸多边形 xy 顶点；凹形/自交/未知区域拒绝，不按邻道 ID 或默认宽度补造自由空间 |
| `ObstaclePrediction` | 目标中心、长宽、朝向、世界速度 vx/vy、相对预测时限，以及位置/速度不确定范围；None 朝向用外接圆，未知速度不补 0 |
| `ValidationBudget` | 有限检查数、细分深度、最小时间区间和本进程单调时钟截止；是调用者给的检查预算，不是已标定循环周期 |

空障碍列表只表示调用者为该独立检查明确提供了空列表；校验器不证明传感器视野或漏检范围。真实接入仍需公共来源、覆盖和原截止门槛，不能以几何检查重新使过期输入有效。

结果为内部字典：`status` 区分 `safe/unsafe/inconclusive/invalid`，并记录原因、约束、检查次数、耗时、模型假设及有证据的间隙下界。只有全范围检查证实后才给安全结果；预算不足、预测时限不足或无法证实不是安全。它不是 `Trajectory.valid`，也不是向决策发送的正式反馈。

以下小车尺寸与限制全部为手写数学例子，演示 2 m 直线路段的检查；既有真实车辆预设另在数据请求中保留，不用本例替代。

```python
import time
from core.interfaces import TrajectoryPoint
from members.planning.candidate_validation import (
    VehicleGeometry, MotionLimits, ValidationBudget, validate_candidate,
)

points = [TrajectoryPoint(0, 0, 1, 0, 0), TrajectoryPoint(2, 0, 1, 0, 2)]
result = validate_candidate(
    points, 1, VehicleGeometry(1.0, 0.5, 0.3, 0.8),
    MotionLimits(8, 3, 4, 4, 0.7, 4, 0.1, 0.01),
    [(-2, -2), (5, -2), (5, 2), (-2, 2)], [],
    ValidationBudget(1000, 16, 0.0001, time.monotonic() + 1.0),
)
assert result["status"] == "safe"
```

例中的 1 秒只作离线演示检查截止，不是在线规划预算。正式预算应由实际循环周期、输入截止和其他模块耗时确定。

## 方法与可证明范围

整车使用带前后悬的有向矩形，目标使用有向矩形；未知朝向目标使用覆盖所有朝向的外接圆。几何间距检查完整边和内部，接触视为冲突。道路检查整个矩形相对于凸区域的边界距离，因此可发现后轴仍在路内但前悬/车角越界。

速度/时间采用分段恒定切向加速度模型：段长与 `(v0 + v1) * dt / 2` 在显式容限内一致。段内按积分行程插值后轴位置，heading 按空间比例取最短角度；同时核对方向、曲率/转角、速度、纵横加速度及采样转角变化。该模型和容限是检查假设，不构成严格无侧滑动力学或轮胎/执行器模型。

容限内的距离残差会使空间映射比例变化，组件按映射后的实际名义速度/加速度复核限制，保留原点不变；不能用容限放过插值后的超速。三点几何曲率另行检查，防止错误的 heading 属性掩盖折线路径转向需求。转角变化率等仍为离散约束，段接头的连续动力学与实际跟踪另需验证。

几何检查使用连续的实际移动段，跨过任意数量的同位置零速停留点；以移动段的方向与长度核对转弯需求，并使用两侧实际名义速度核对横向加速度。转角变化率保留原轨迹到达转折位置的时刻。完整原轨迹仍用于速度/时间和连续碰撞检查，停留期间的动态占用不会被去重删除；非零速度或车体旋转仍不能作为静止段通过。

连续碰撞不只看端点。每个时间区间在中间时刻计算整车与目标/道路间距，再扣除区间内任何车体点可能移动的上界：后轴位移加上“最远车角半径 × 航向变化”。目标再计恒速位移与显式不确定范围。如果剩余间距仍为正，可证实整个区间；否则自适应二分。达到深度、检查数、时间截止或分辨率仍不能证实时返回不确定，不能漏掉细障碍后仍宣称通过。

这是给定插值、恒速固定朝向目标与不确定范围内的名义时空验证。控制当前按空间进度消费 `v(s)^2`，不保证车辆在轨迹相对时间精确到达。依靠时间错开的通过结果，在实际接线前仍需跟踪误差、响应延迟与时钟误差的界限；当前不保证实际动态避碰。

保留主分支 `reference_recovery` 的旧走廊/几何修复；此组件处理显式新候选和目标时间占用，不修改已有目标投影、运动分类或当前车道跟踪。生产参数来源未知时明确拒绝；示例/测试参数均为合成工程条件，不标为实测能力。
