# 带目标的前进轨迹约束

2026-10-02 P0 集成。固定入口仍为 `plan(perception, decision)`，Python 3.6，不连接 SDK、不改变发送开关。完整字段与修复依据见 [链路修复](../../P0_HANDOFF_FIXES.md)。

## 目标包络与业务净距

- 只接受新鲜、可用的正式 Sensor API 目标，目标位置/速度/尺寸必须有效。
- 有有限朝向时按目标矩形与主车横向宽度求参考路径首次接触；旋转目标采用保守扩展的矩形半空间。`Target.heading=None` 时保留外接圆，不把缺失朝向当成 0。
- 参考起点是 GPS 后轴投影，首次接触距离扣一次后轴到车头距离，再扣决策 `obstacle_clearance_m`。已知 `decision.stop_distance` 是已经扣完业务余量的停车点，不再次扣除。
- 新决策默认静态障碍余量 0.5 m、跟车净距下界 10.5 m；规划不再自行另加 4 m。旧生产者字段为 -1 时才使用 `NEVC_PLANNING_OBSTACLE_MARGIN_M`（默认 4 m）回退。
- 同车道静止或沿路径前进的目标可产生先起步再停车的轨迹。移动前车按可能立即停在当前位置处理，逐帧重算，不预测其未来轨迹。
- 先判断当前/预测横向运动包络是否进入参考路径，再处理不支持的迎面或横穿运动。邻道内正常对向车不强制停车；真正冲突、无效尺寸/来源和不可行减速仍保持制动出口。
- 决策 `precision_stop` 传递到既有轨迹字段。未知停车点不启用精确停车，不编造远端停点；在动请求制动、静止保持。

## 必需车身尺寸

带目标的移动轨迹必须同时提供 `NEVC_VEHICLE_FRONT_OFFSET_M`（后轴到车头，米）和 `NEVC_VEHICLE_HALF_WIDTH_M`（最大半宽，米）。用户主车预设轴距 291.87 cm、车头到前轴 100 cm、车宽 180 cm；`scripts/StartCaptain.bat` 默认传入 3.9187 m 和 0.9 m，已有环境覆盖优先并记入日志。更换车型须重新核对；直接启动 Python 须自行设置尺寸。

决策共用车头偏移；显式 `NEVC_DECISION_FRONT_OFFSET_M` 不应与规划设置成不同数值。转向及制动响应标定独立于尺寸确认。

## 横向运动与参数

归属已核实的当前车道目标，需真实车道宽度、有限朝向和有效投影，检查矩形横向占宽加 `abs(横向速度) * max(观察时间, 自车速度/规划减速度)` 能否留在车道。接受后将整个漂移扩展横向包络；不会因运动小就直接丢弃，也不会把纯横向扩展作为额外纵向业务间距。

实验参数保留 `NEVC_PLANNING_LATERAL_MARGIN_M=0`、`NEVC_PLANNING_MOTION_TOLERANCE_MPS=0`、`NEVC_PLANNING_LATERAL_GUARD_TIME_S=3` 和 `NEVC_PLANNING_DECELERATION_MPS2=2`，单位分别为米、米/秒、秒和米/秒²。超容差且无可靠几何、可能离开车道或迎面冲突仍拒绝普通移动。

## 验证边界

这是沿前进参考的局部约束，不是完整转弯整车扫掠或动态碰撞预测。未知朝向与旋转对象可能更早停车，独立近风险保护也可能提前制动。模型验证不等于车辆能按目标距离刹停或比赛得分。

离线覆盖真实 `decide → plan → compute_control` 的静态接近、直线/弯道跟车停走、红绿灯启停；新增测试检查共享净距、未知朝向、邻道对向车、真实侵入、信号失效与恢复。真实验收须记录正式目标源、目标朝向和尺寸、车头净距、停车误差、制动反馈和发送回执。前阶段历史试验见 [前进规划第二阶段](FORWARD_CONSTRAINTS.md)。
