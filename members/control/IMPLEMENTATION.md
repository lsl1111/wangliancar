# 首版控制算法与接入状态

首版仅跟踪**前进挡**、同一世界坐标系中以 GPS 后轴为参考点的轨迹。`members/control_stub.py` 的 `compute_control(perception, trajectory)` 签名不变；运行层在启动时注入控制配置。控制模块不调用 SimOne API、不直接发送指令。当前规划只生成本车道前向轨迹，并明确拒绝目标车道与当前车道不同的请求，所以整条链尚不能变道。控制器按输入轨迹做几何跟踪，没有专门禁止前进变道轨迹，但还未针对变道的曲率、车道切换与车辆响应验收，不能据此声称变道可用。倒车会被控制器明确拒绝；泊车需要倒车/低速几何与状态支持；高速又受首版 8 m/s 上限和未验收的车辆响应限制。

## 每帧处理

1. 验证 GPS、新鲜度、同帧的有效轨迹、Drive 挡、有限位置/航向/速度、单调递增帧和本机单调时钟间隔。未配置的可选传感器不参与控制入口的质量门槛；场景必需的目标和车道由上游决策及运行层监护。
2. 急停标记先于路径几何处理：清速度积分、零油门和零转向，使用配置的紧急制动值。有效的零长度急停轨迹可执行；参数未配置时输出无效，由独立安全监护处理。
3. 对规划输出的非急停零长度停车轨迹，先核对所有点都在车旁且速度为零；车辆仍在移动时使用普通制动上限，低速时使用保持刹车，油门和转向均为零。其他普通路径去除相邻重复点，并保留重复位置上的最低限速；拒绝非有限数据、过大点距、方向相反、离车过远、路径终点之后及交叉处无法确定进度的投影。将后轴投影到最近线段，以累计弧长 `s` 表示进度。
4. 预瞄弧长 `D=min(Dmax,D0+Tv·v)`，沿轨迹插值得到目标点。转车体坐标后用 `κ=2·y/(x²+y²)` 计算曲率，`δ=atan(L·κ)` 得前轮角，再按配置的有效最大角和方向映射到归一化转向；这组映射仍需现场核对。目标在车后或弦长过短时拒绝普通跟踪。
5. 速度参考取当前位置的轨迹点速度，并受前方低速点的 `sqrt(v_future²+2ad)`、全局速度上限、停车距离和已知路径末端的 `sqrt(2ad)` 约束。停车意图 `target_speed=0` 时不为了接近停止线再加速。纵向采用带积分边界及饱和防积累的 PI，将速度误差经车型踏板系数映射为互斥的油门或刹车。
6. 低速且参考速度接近零时进入 `HOLD`，以实测保持刹车维持停车；解除停车需连续两帧正速度意图。正常跟踪限制转向变化、油门上升和刹车释放速度；刹车增加、急停和故障切油不受普通速率限制。

`ControlOut.diagnostics` 随 `latest_pipeline.json` 发布状态、路径进度/剩余长度、横向及航向误差、参考速度、预瞄点、曲率、前轮角与计算间隔。正常状态为 `TRACK`、`STOPPING`、`HOLD` 或 `EMERGENCY`；输入错误为 `FAULT_STOP`，输出无效。运行层在已开启发送时把控制无效转为独立的 `fault_stop` 刹车候选。发送失败、GPS 失效或连接断开时不保证车辆已经停车。

## 车型标定与发送边界

默认配置 `control_calibrated=true`、`send_control=false`、`safety_brake_enabled=false`。`control_calibrated` 是沿用的字段名，此处仅表示九个控制映射参数已配置且通过数值校验，**不表示车辆响应已经标定或允许发送**。有效的 GPS 和轨迹可产生 `ControlOut.valid=True` 的离线候选。默认值面向平台资源库中的 SimOne-Car 主车：

| INI 参数 | 含义 |
| --- | --- |
| `control_wheelbase_m=2.9187` | 平台主车预设的轴距 291.87 cm，换算为米 |
| `control_front_steer_max_rad=0.5` | 前轮角到 SDK 归一化转向的暂定有效比例；平台显示的 540° 是方向盘限位，不是此参数 |
| `control_steering_sign=-1` | 本机 SimOne SDK 附带的 Autopilot 示例对左侧路径使用负转向；现场仍需核验 |
| `control_throttle_per_mps=0.1`、`control_brake_per_mps=0.2` | PI 速度需求到踏板比例的工程初值，需按速度响应调节 |
| `control_hold_brake=0.1`、`control_emergency_brake=0.8` | 静止保持与紧急制动候选比例，停车/制动能力尚未实测 |
| `control_max_throttle=0.25`、`control_max_brake=0.35` | 普通控制的试运行踏板上限 |

若主车并非 SimOne-Car，应通过独立配置替换这组参数。先保持 `send_control=false` 检查 06 的诊断、转向符号和停车意图；再按团队流程做低速发送验证并调整映射。正常发送及安全制动发送均要求 `safety_brake_enabled=true`，避免车辆有驱动指令却没有制动出口。软件预瞄、PI 增益、2 m/s² 预览减速度及 8 m/s 首版速度上限也是待调算法参数，不能作为已验证的车辆响应。

离线回归：`E:\Sim-One\Tools\python36\python.exe -B -m unittest discover -s tests -v`。测试覆盖独立注入的示例数值及默认 SimOne-Car 候选配置，只验证公式、状态、边界和离线数据链；NEVCsim 尚未提供 06 的连续实测帧，因此车辆响应、停止距离及参数仍未验收。
